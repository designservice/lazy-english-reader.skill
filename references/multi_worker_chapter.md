## 规则

1. **每位人物 2–4 个小标题**。不要每个人物都拉成迷你独立章节——会让笔记臃肿到无法读。
2. **每位人物 1–3 个嵌入式引文**，挑主轴金句、独白色彩浓的留下来。引号块格式按 [`writing_style.md`](writing_style.md) 第 8 条（中文 primary、英文小字斜体）。
3. **编辑解读放在章节末尾，不分人**。3–6 条。覆盖：章名含义、关键术语 / 制度（如各种行业术语 / 历史法律条款 / 工艺术语 / 社会概念的出处和含义）、历史背景、跨章呼应。
4. **章节定位段（H1 下面的 block quote）必须点出"为什么这几个人被放一起"**——是作者的编排逻辑，不是事实清单。
5. **人名首现：中文音译（English Name）**，之后只用中文音译（按 [`writing_style.md`](writing_style.md) 第 11 条）。
6. **小标题取自具体物件 / 动作 / 数字**（"三万磅钢"、"那扇一百年前的门"、"在床上做数学题"）——禁止"主要观点"、"核心内容"这种学术抬头。
7. **跨章呼应主动写双链**。同一个主题（"看得见的活儿与看不见的活儿"、"你成了你那份活儿"）在多章出现时，让编辑解读里点名链向前面章节。这是为主题归纳打地基。

## 体量参考

| 章节类型 | 中文字数 |
|---|---|
| 单人章节（preface 类 / 一个采访对象） | 1500–2500 |
| 3–4 人章节 | 3000–4000 |
| 5–6 人章节 | 4000–6000 |
| **10+ 人章节**（如 某口述史汽车业一章 13 位口述者） | 主推 5–6 位主角 + 在编辑解读里整合其他人的关键点，**不要硬把 13 人拉成同等长度** |

## 如果整章只有 1 个人

用 `references/writing_style.md` 的常规章节模板就行，**不用走这个文件**。
